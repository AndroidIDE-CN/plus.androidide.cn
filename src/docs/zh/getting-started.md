# 快速开始

AIDE Plus 是运行在 Android 设备上的集成开发环境，可以直接在手机或平板上编写、构建和安装 Android 应用。

## 1. 下载安装

1. 打开本站的 [下载页](/download)，下载最新版本中标记为“推荐”的 APK。
2. 在系统设置中允许浏览器或文件管理器“安装未知应用”。
3. 打开 APK 完成安装。

> 新版本会同时提供几个包名不同的 APK（例如 `io.github.zeroaicy.aide`、`io.github.zeroaicy.aide.beta`、`io.github.zeroaicy.aide1`）。它们可以同时安装、互不覆盖，一般用户只需要推荐的那一个。

## 2. 初始设置

首次启动时会打开初始设置向导，依次完成：

| 步骤 | 说明 |
| --- | --- |
| 条款 | 阅读并同意使用条款 |
| 权限 | 授予存储等必要权限 |
| 构建工具 | 安装构建所需的工具 |
| 基础设置 | 选择主题、编辑器等常用选项 |

以后可以在首页菜单的“初始设置向导”中重新进入。

## 3. 首页

首页分为 **项目**、**插件**、**共享** 三个标签页：

- **项目**：最近打开的项目列表，右下角按钮可以新建项目、打开本地项目或从 Git 克隆。
- **插件**：内置功能与第三方插件的开关和详情。
- **共享**：浏览社区分享的项目并一键导入。

如果希望启动后直接进入编辑器，可以在设置中开启“启动时直接进入编辑器”，编辑器菜单里的“首页”随时可以回来。

## 4. 第一次构建

1. 在项目页新建一个 Android 应用项目。
2. 等待依赖下载和代码分析完成。
3. 点击工具栏的运行按钮，构建完成后会自动安装生成的 APK。

构建过程可以在构建流程页查看，详见 [调试与 Logcat](/docs/debug-logcat)。
