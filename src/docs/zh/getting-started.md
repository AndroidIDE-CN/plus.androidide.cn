# 快速开始

AIDE Plus 是运行在 Android 设备上的集成开发环境，可以直接在手机或平板上编写、构建和安装 Android 应用。

## 1. 下载安装

1. 打开本站的 [下载页](/download)，下载最新版本中标记为“推荐”的 APK。
2. 在系统设置中允许浏览器或文件管理器“安装未知应用”。
3. 打开 APK 完成安装。

> 新版本会同时提供几个包名不同的 APK（例如 `io.github.zeroaicy.aide`、`io.github.zeroaicy.aide.beta`、`io.github.zeroaicy.aide1`）。它们可以同时安装、互不覆盖，一般用户只需要推荐的那一个。

## 2. 初始设置

首次启动时会打开初始设置向导，依次完成：

| 步骤 | 说明 |
| --- | --- |
| 条款 | 阅读并同意使用条款 |
| 权限 | 授予存储等必要权限 |
| 构建工具 | 安装构建所需的工具 |
| 基础设置 | 选择主题、编辑器等常用选项 |

以后可以在首页菜单的“初始设置向导”中重新进入。没有授予存储权限时，首页也会提示前往初始设置。

## 3. 首页

首页底部有 **项目**、**插件**、**共享** 三个标签页。新建、打开和克隆项目都在项目页右下角的圆形按钮里。详细说明见 [首页、插件与共享](/docs/home-plugins)。

想跳过首页直接进入编辑器：**设置 → 通用 → 窗口 → 启动时直接进入编辑器**。在编辑器中随时可以用 **菜单 → 首页** 回来。

> 本文档中的“菜单”指编辑器右上角的主菜单，“设置”在 **菜单 → 更多 → 设置**。设置首页有搜索框，输入关键字可以直接定位到设置项。

## 4. 第一次构建

1. 在项目页新建一个 Android 应用项目。
2. 等待依赖下载和代码分析完成。
3. 点击工具栏的运行按钮，构建完成后会自动安装生成的 APK。

构建过程可以在构建流程页查看，详见 [调试与 Logcat](/docs/debug-logcat)。
