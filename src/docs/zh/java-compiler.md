# Java 与 Kotlin

## Java 语法支持

默认的语法分析器已经支持部分 Java 8、9、11 语法，日常写代码不需要额外设置。

需要更高版本时可以启用 **ECJ**（Eclipse Java 编译器）：

- 在设置中开启 ECJ 编译后，可以编译到 **Java 23**，包括 Lambda 等特性。
- 开启 ECJ 格式化后，可以正确格式化高版本 Java 代码。
- 自定义的 class 解析器可以读取高版本 class 文件。

> 如果找不到对应选项，可以使用设置页的搜索功能，搜索“ECJ”或“Java”。

Java 项目也可以引用 Android API，适合编写不需要界面的工具类代码。

## Kotlin

Kotlin 的补全、实时错误、导入修复与跳转使用 AIDE Plus 自有的引擎，基于 Kotlin 2.4.20 官方解析器，大项目也能保持流畅。

- kotlinc 与 KSP 共用一份编译器，减少工具链体积。
- 可以在设置中调整 Kotlin 代码风格。
- Kotlin 编译器版本可以在工具链管理页中管理。

## 跳转到源代码

开启“跳转到源代码”后，对依赖库和 `android.jar` 中的类可以直接跳转到源码。Android 平台源代码需要先在 SDK 管理器中下载，在源码中可以继续跳转。

## 编辑器小技巧

- 符号栏默认三行，带撤销、重做和保存按钮。
- 代码颜色可以自定义，Java 支持语义高亮。
- AIDL、CMake、TOML 文件也有补全、错误提示与跳转。
- 编辑器菜单中的“注释预览”可以查看渲染后的文档注释。
