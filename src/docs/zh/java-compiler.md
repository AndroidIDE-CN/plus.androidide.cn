# Java 与 Kotlin

## Java 语法支持

默认的语法分析器已经支持部分 Java 8、9、11 语法，日常写代码不需要额外设置。

需要更高版本时可以启用 **ECJ**（Eclipse Java 编译器）：

1. 打开 **设置 → 代码与编译 → 编译器实现**，开启 **启用Eclipse Compiler For Java[ecj]**。
2. 重启 AIDE Plus。之后可以编译到 **Java 23**，包括 Lambda 等特性。

ECJ 只接管代码分析与编译。补全和跳转可以另外开启实验性的 JDT 引擎：

| 设置项 | 位置 |
| --- | --- |
| 启用 JDT 成员补全 | 设置 → 代码与编译 → 代码补全 |
| JDT 完整补全（独立 Java 补全引擎） | 设置 → 代码与编译 → 代码补全 |
| 启用 JDT 跳转与参数提示 | 设置 → 代码与编译 → 跳转与源码 |
| 后台代码分析 | 设置 → 代码与编译 → 错误检查 |

### 格式化

**设置 → 代码与编译 → Eclipse Java 格式** 可以设置缩进、行宽、大括号位置、保留空行、注释与注解换行。开启“启用EclipseJavaFormat”后，用 **菜单 → 对齐代码** 格式化当前文件。

### 新的 Class 解析库

**设置 → 代码与编译 → 新的Class解析库** 用于读取高版本 class 文件和 Java 8 API。修改后重启，再执行 **菜单 → 更多 → 项目 → 构建刷新**。

Java 项目也可以引用 Android API，适合编写不需要界面的工具类代码。

## Kotlin

Kotlin 的补全、实时错误、导入修复与跳转使用 AIDE Plus 自有的引擎，基于 Kotlin 2.4.20 官方解析器。

1. 在 **设置 → 构建与运行 → Native代码支持 → 工具链管理** 中安装 Kotlin 编译器。
2. 在 **设置 → 代码与编译 → 编译器实现** 中开启 **启用 Kotlin 编译**，按需开启 **自动打包 Kotlin 标准库**。
3. 重启后，`.kt` 文件会参与构建。

| 设置项 | 位置 | 作用 |
| --- | --- | --- |
| 启用 Kotlin 语义补全 | 代码与编译 → 代码补全 | 语义补全，失败时回退关键字补全 |
| Kotlin 实时错误检查 | 代码与编译 → 错误检查 | 编辑时直接显示错误，无需先构建 |
| 用 Kotlin 编译器完整检查 | 代码与编译 → 错误检查 | 停止输入后用编译器检查整个模块 |
| 在错误列表 / 编辑器中显示 Kotlin 警告 | 代码与编译 → 错误检查 | 两处警告分别开关 |

**快速修复**：在报错的代码上长按，选择 **修复 (Kotlin)**。支持导入、拼写、初始化、类型、open/override、`@Composable`、`@OptIn` 等 30 余种修复。错误列表右侧的信息按钮可以查看处理建议和完整诊断。

**代码风格**：**菜单 → 更多 → 格式 → 配置代码风格**。

## 跳转到源代码

在 **设置 → 代码与编译 → 跳转与源码** 中：

- **跳转到库源代码**：解析 Maven 依赖时下载 `-sources.jar`，跳转到库中的类时打开源代码。
- **查看 class 时显示反编译源码**：没有源码时显示内置 CFR 反编译出的 Java 代码（只读），可以继续跳转；同一页可以更换反编译引擎。

`android.jar` 的源码需要先下载：**设置 → 代码与编译 → SDK 与平台数据 → Android SDK 平台**。
