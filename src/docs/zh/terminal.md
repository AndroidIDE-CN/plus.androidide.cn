# 终端与 AI 助手

## 内置终端

AIDE Plus 集成了 Termux 终端：

- 全宽标签栏与下方工具按钮
- 8 套配色，额外按键可同步终端配色，支持组合修饰键与长按连发
- 文本选择手柄、查找、`~/.termux` 配置
- “更多”菜单提供可搜索的链接列表

## 运行环境

在 **终端 → 环境** 中管理运行环境：

- 可以下载 Termux bootstrap 或 Linux 发行版，后台下载，可暂停并断点续传。
- 同一个发行版可以安装多个实例，例如 `ubuntu1`、`ubuntu2`。
- 环境可以重命名、备份为 `.aide-env.tar.gz` 并在之后恢复。
- “软件源”菜单可以直接编辑 APT 或 pacman 的源配置。

> 备份未加密，可能包含私钥、密码和令牌，请只导出到可信位置。

### 一键配置 Gradle 环境

终端环境页可以为 Termux 或 Linux 容器一键配置 Gradle 构建环境，包括 JDK 17、Android SDK 与兼容新版 AGP 的 aapt2。配置完成后即可配合 [Gradle 命令构建](/docs/project-build) 使用。

## AI 助手

在编辑器右侧抽屉中打开 AI 助手，可以与模型讨论当前项目：

- 读取、搜索、修改项目文件，修改前显示差异，可撤销上一轮修改。
- 支持 OpenAI 兼容、Anthropic 与 OpenAI Responses 接口，填写自己的接口地址和密钥即可使用。
- 支持技能、远程 MCP、子代理、长期记忆与联网搜索。
- 可以调用翻译补齐字符串资源，或在构建容器中运行命令。
