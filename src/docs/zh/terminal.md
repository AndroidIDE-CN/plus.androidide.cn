# 终端与 AI 助手

## 内置终端

打开方式：**菜单 → 工具 → 显示终端**，或在文件浏览器中长按文件夹选择 **在终端中打开**。新会话优先使用项目根目录。

- 全宽标签栏与下方工具按钮
- 8 套配色，额外按键可同步终端配色，支持组合修饰键与长按连发
- 文本选择手柄、查找、`~/.termux` 配置
- “更多”菜单提供中断任务、文本导出、会话诊断和可搜索的链接列表

## 运行环境

在 **设置 → 构建与运行 → 运行 → 终端环境** 中管理运行环境，可选 Termux 软件包、Linux 发行版（Ubuntu 22.04 / 20.04、Debian 12、Arch Linux）和系统 Shell：

- 可以下载 Termux bootstrap 或 Linux 发行版，后台下载，可暂停并断点续传。
- 同一个发行版可以安装多个实例，例如 `ubuntu1`、`ubuntu2`。
- 在环境右侧的“更多”中可以 **重命名环境**、**备份环境**（`.aide-env.tar.gz`）、**恢复环境备份** 和编辑 **软件源**（APT 或 pacman）。
- 试验后端：**使用 Cortex 运行 Linux（试验）** 和需要 su 授权的 Root chroot，默认仍使用 PRoot，开关只影响新启动的 Linux。

> 备份未加密，可能包含私钥、密码和令牌，请只导出到可信位置。

### 一键配置 Gradle 环境

终端环境页可以为 Termux 或 Linux 容器一键配置 Gradle 构建环境，包括 JDK 17、Android SDK 与兼容新版 AGP 的 aapt2。配置完成后即可配合 [Gradle 命令构建](/docs/project-build) 使用。

## AI 助手

打开方式：**菜单 → 工具 → AI 助手**，或点编辑区右边缘的 **AI** 手柄（手柄可在 **设置 → AI 与翻译 → 显示 AI 手柄** 开关，可上下拖动）。选中代码后也可以选 **询问 AI 助手**。

1. 第一次打开时点 **配置模型**，选择接口类型（OpenAI 兼容、Anthropic 或 OpenAI Responses），填写 API Key 和模型名称。
2. 在输入框中提问或让它修改代码。修改前会显示差异，可以撤销上一轮修改。
3. 页面菜单中可以查看历史、新建对话，管理技能、远程 MCP、子代理、长期记忆与联网搜索。

## 本机 MCP 服务

**设置 → AI 与翻译 → 本机 MCP 服务** 会在 `127.0.0.1` 上提供 MCP，供 Termux 中的 Claude Code、Codex 等 AI 客户端读取当前项目与错误：

- 默认只读；需要客户端修改文件时，开启同一页的 **允许修改文件**。
- 端口、令牌和连接方式在同一页查看。

## 翻译

**设置 → AI 与翻译** 中还有代码翻译（为代码提示提供翻译）和文本翻译，可以选择翻译引擎。在编辑器中长按代码选 **翻译** 即可使用。
