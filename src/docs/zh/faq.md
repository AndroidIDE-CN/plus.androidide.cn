# 常见问题

## 为什么不再开源？

有人在违反 AGPLv3 协议的情况下使用本项目代码，并通过 VMP 等手段加固 DEX 规避开源义务。为此项目停止公开源代码，GitHub 仓库仅用于发布 APK。基于历史 AGPL 版本的衍生作品仍需公开源代码、注明来源并保持 AGPLv3 协议。

## 下载页的几个 APK 有什么区别？

它们是包名不同的同一版本，可以同时安装、互不覆盖。一般选择标记为“推荐”的 `io.github.zeroaicy.aide`；想保留旧版本或测试新功能时再安装其它包名。

## 下载很慢怎么办？

可以在下载页切换下载线路，或者到 QQ 群获取安装包。下载完成后建议核对 SHA-256。

## 构建时提示内存不足？

新版本参照 AGP 重写了 R 类生成与 DEX 合并，大多数项目已经不会再出现这个问题。如果仍然出现，可以关闭暂时不需要的保护插件，或先更新到最新版本。

## 依赖下载失败？

- 检查网络是否能访问对应的 Maven 仓库。
- 连不上的仓库会被自动跳过，可以在 `repositories` 中添加可用的镜像仓库。
- 打开项目时会先下载缺失的依赖再分析代码，耐心等待下载完成。
