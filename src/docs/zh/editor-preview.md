# 编辑器与预览

> “菜单”指编辑器右上角的主菜单；“长按菜单”指在代码上长按弹出的菜单。

## 编辑辅助

在 **设置 → 编辑器** 中，下面四项可以分别开关：

| 设置项 | 作用 |
| --- | --- |
| 缩进引导线 | 显示缩进层级，不改动文件内容 |
| 括号配对引导线 | 突出 Java/Kotlin/C/C++/JSON/JSONC 括号与 XML/SVG/HTML 标签的当前层级 |
| 智能括号配对 | 括号与引号配对、包裹选区、成对退格；XML/SVG 标签闭合与属性引号配对 |
| 行内错误提示 | 在代码后显示实时诊断摘要，点按查看建议与完整错误 |

同一页还有字体、自动保存、**编辑器启用异步读取**（大文件）和 **代码高亮 → TextMate 语法管理**。

符号栏在 **设置 → 快捷输入与快捷键**：可以设置 1 到 4 行、自定义各语言的快捷符号和快捷代码，以及外接键盘快捷键。

## 文件结构

**菜单 → 文件结构** 列出当前 `.java`、`.kt`、`.class` 文件中的类、方法与字段：

- 顶部可以搜索，按 全部 / 类型 / 方法 / 字段 筛选，点按跳转。
- Java 方法可以查看 **流程图**，并复制 Mermaid 源码。

## 跳转与查找用法

- **菜单 → 查找…** 中有查找用法、在文件内查找、在项目内查找、跳转到行。
- Java `native` / Kotlin `external` 方法与 C/C++ 中的 JNI 函数可以互相跳转，查找用法会列出另一侧的实现与调用。
- 引用 AIDL 生成的接口、Stub 与方法时会跳到 `.aidl` 声明。
- 库源码与反编译设置见 [Java 与 Kotlin](/docs/java-compiler)。

## 长按菜单

在代码上长按可以使用：翻译、修复、**修复 (Kotlin)**、跳转、**注释预览**、查看文档、**断点**，以及重构（重命名、内联变量、引入变量、提取方法）和代码（整理导入、添加 try-catch、生成 getter/setter 与构造器、提取资源）。选中代码后还可以 **询问 AI 助手**。

## 预览

### Compose 预览

1. 打开带有 `@Preview` 函数的 Kotlin 文件。
2. 点编辑区右上角的预览按钮，在源码与预览之间切换。
3. 打开预览时会增量编译当前模块的 Kotlin 与 Java（包括未保存的修改），叠加在最近一次构建上渲染；编译错误可以点按跳到对应行。

自动刷新开关：**设置 → 代码与编译 → 编译器实现 → Compose 预览自动刷新**（代码停止变化 1.5 秒后刷新）。需要先开启 Kotlin 编译，见 [Java 与 Kotlin](/docs/java-compiler)。

### Markdown 预览

打开 `.md` 文件后点右上角的预览按钮。支持 Mermaid 图表、KaTeX 数学公式、代码高亮、脚注、`[TOC]` 目录与标题跳转、GitHub 提示块（`> [!NOTE]`）、表情短代码和 YAML 前置信息，全部离线渲染。

### 文件预览

在文件浏览器中点按非代码文件即可预览：

| 类型 | 预览内容 |
| --- | --- |
| 图片、音视频、PDF、字体 | 直接查看，工具栏在顶部 |
| jar / aar / zip / apk | 按包查看与搜索，apk 显示图标、名称、包名与版本 |
| CSV / TSV、JSON / YAML / TOML / properties | 表格或结构树，可直接编辑，保留原格式，可撤销 |
| SQLite | 只读查看表 |
| 证书、密钥库 | 指纹；密钥库输入密码后查看证书 |
| .dex、.class | 类列表与反编译源码 |
| .so、resources.arsc、二进制清单 | ABI、段与导出符号、资源表 |
| 其它 | 十六进制与带行号、可查找的文本 |

不需要的预览可以在 **首页 → 插件** 中关闭。

## 布局与清单

- 打开布局 XML 后，**菜单 → 设计器** 进入可视化布局设计器。
- **菜单 → 清单编辑** 打开清单编辑器。
