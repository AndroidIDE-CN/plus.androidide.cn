# 首页、插件与共享

从桌面启动 AIDE Plus 会进入首页，底部导航切换 **项目**、**插件**、**共享**。在编辑器中用 **菜单 → 首页** 可以随时回来。

## 项目

项目页把打开历史与 `AppProjects` 中的项目合并成一个列表：

- 按目录分组，置顶的项目在前，可按最近打开、最近修改、名称、路径排序，也可以搜索。
- 每个项目显示图标（`.idea/icon.svg`、启动图标等）、类型、模块数、Git 分支与包名。
- **长按** 项目或点更多按钮进入项目管理：详情、分享为不含构建产物的 zip、重命名、删除。详情页可以搜索本地和远程跟踪分支。

右下角的圆形按钮里有三个操作：

| 操作 | 说明 |
| --- | --- |
| 新建项目 | 选择模板创建，Gradle 模板使用 AGP 8.13 写法（`plugins`、`namespace`、compileSdk 36） |
| 打开项目 | 浏览目录打开；用系统文件选择器打开时，会确认导入为本地工作副本，修改不会自动同步回来源 |
| 克隆 Git 仓库 | 输入仓库地址克隆 |

> 下载过旧版“更多”模板的用户，可以在新建对话框的“更多”中重新安装内置模板。

## 插件

插件页顶部是常用工具（例如图标库），下面分为 **已安装** 与 **内置**：

- 每个插件、每个内置分类各占一项，点按进入详情页，可以逐项开关组件（编辑器预览、文件预览、Markdown 扩展、反编译引擎等），调整相关设置，查看 ID、来源与介绍。
- **导入插件**：导入 `.aplug` 插件包，支持 Java 与 Lua 插件。Lua 插件无需编译即可添加文件预览、编辑器预览与 Markdown 样式。插件说明可以一键翻译成界面语言。自己写插件见 [插件开发](/docs/plugin-dev)。
- 插件以 AIDE Plus 的全部权限运行，可以读取和修改你的项目，请只安装可信来源的插件。卸载在插件详情页。

## 共享

共享页分为 **精选** 与 **发现**，可以按标签筛选，点 **导入** 用克隆对话框预填仓库地址。

- **精选**：维护者审核后收录的项目。
- **发现**：GitHub 上带有 `aide-plus-project` topic 的公开仓库。给你的仓库加上这个 topic 就会出现在这里，不需要审核。
- 未登录的 GitHub 搜索约 10 次/分钟，受限时稍后重试即可。

## 初始设置

首次启动会进入初始设置向导：条款 → 权限 → 构建工具 → 基础设置 → 完成。以后可以从首页菜单的 **初始设置向导** 重新进入。

想跳过首页：**设置 → 通用 → 窗口 → 启动时直接进入编辑器**。
