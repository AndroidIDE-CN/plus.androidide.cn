# 调试与 Logcat

## 构建流程页

构建流程是 BrowserPager 中的独立页面，会保存最近一次构建的：

- 构建阶段与进度
- 编译输出
- 错误详情与失败历史

构建流程页会在点运行后显示，构建失败时也可以从错误列表打开，支持停止和复制输出。

## Logcat

AIDE Plus 提供两种 Logcat，共用同一份来源、过滤条件、暂停状态和历史记录：

- **日志页**：**菜单 → 更多 → 查看 → 日志**
- **悬浮 Logcat**：**菜单 → 更多 → 查看 → 悬浮 Logcat**，也可以在日志页菜单中选“在悬浮窗中打开”。悬浮窗可以拖动标题栏移动、拖动右下角改变大小，收起为气泡后点按展开、长按关闭。

默认来源为“自动”，按 su → Shizuku → ADRT 的顺序尝试：

| 来源 | 说明 |
| --- | --- |
| su | 需要 Root 权限，可以读取全部日志 |
| Shizuku | 通过 Shizuku 授权读取日志 |
| ADRT | 读取 AIDE Plus 构建的 debug 应用日志，无需 Root |

- 过滤支持最低级别、标签、进程、“只看当前项目的应用”和规则。规则每行一条，例如 `tag:MyApp level:W,E`，以 `-` 开头表示排除。
- 进程和标签过滤都有编辑框和可搜索的候选列表。
- 悬浮窗需要系统的“显示在其他应用上层”权限，兼容 Android 12 及以上版本。

## ADRT 调试

ADRT 是 AIDE 的运行时调试组件：

- 只对 debug 变体（包括 `debug-aide`）注入，release 变体不会注入。
- 普通 debug 构建的日志注入由 **设置 → 构建与运行 → 构建 → 启用adrt日志注入** 控制，默认关闭，需要在 Logcat 里看应用日志时打开。
- `debug` 变体只提供日志；`debug-aide` 变体额外提供断点等逐行调试能力。
- 先运行生成的 debug 应用，ADRT 才能建立运行时连接。

### 断点

在代码上长按选择 **断点** 设置断点，用 `debug-aide` 变体运行后，主菜单中会出现逐过程、步进、跳出、停止等调试命令。

## 缓存日志

AIDE Plus 自己的日志可以在 **菜单 → 工具 → 管理缓存日志** 或 **设置 → 关于 → 管理缓存日志** 中查看、分享或删除，反馈问题时可以打包分享全部日志。
