# R8 Shrinker and Obfuscator

:::tip 提示

R8 在 Android 项目中的Gradle文件配置后才能启用

:::

**R8 Shrinker and Obfuscator**是 **Android** 官方推出的一款 **代码优化、压缩和混淆** 工具。它是 **ProGuard** 的替代方案，并且与 **D8** 深度集成，用于优化 Android 应用的 **DEX 代码**。


## **R8 的作用**
R8 主要用于 **减少 APK 体积** 和 **提高运行时性能**，其核心功能包括：
1. **代码压缩（Shrinking）**：移除未使用的类、方法和字段，减少应用体积。
2. **代码优化（Optimization）**：对 Java 字节码进行优化，例如内联方法、移除死代码等，提高执行效率。
3. **代码混淆（Obfuscation）**：替换类名、方法名和变量名，使代码更难被反编译。
4. **DEX 生成（Dexing）**：与 **D8** 结合，将 Java 字节码转换为优化后的 `.dex` 文件。



## **R8 vs ProGuard**
| **对比项** | **R8** | **ProGuard** |
|-----------|--------|-------------|
| **开发者** | Google | Guardsquare |
| **功能** | 混淆 + 压缩 + DEX 转换 | 仅混淆和压缩 |
| **速度** | 更快（直接在 D8 阶段优化） | 较慢（单独运行） |
| **默认启用** | Android Gradle Plugin 3.4+ | 需手动配置 |
| **兼容性** | 支持 ProGuard 规则 | 仅支持 ProGuard  |


## **R8 的使用**
- **R8 在 Android 项目中的Gradle文件配置后启用**：  

- **自定义混淆规则**（兼容 ProGuard 语法）：  
  在 `proguard-rules.pro` 文件中，你可以定义规则，例如：
  ```proguard
  # 保留 MainActivity 及其所有方法
  -keep class com.example.app.MainActivity { *; }
  
  # 保留带 @Keep 注解的类和方法
  -keep @androidx.annotation.Keep class * { *; }
  
  # 禁用代码优化（仅混淆）
  -dontoptimize
  ```
