# D8 Dex Compiler

:::tip 提示

目前默认启用 **D8** 因为谷歌已经弃用了 **DX**

:::

**D8 Dex Compiler**，是 **Android** 官方推出的一款用于将 **Java 字节码（.class 文件）** 转换为 **Dalvik 可执行文件（.dex 文件）** 的编译器。

## **D8 Dex Compiler 介绍**
- **D8 是什么？**  
  D8 是 **Android Studio** 和 **Android Gradle 插件** 默认使用的 **DEX 编译器**，它的作用是将 **Java 字节码** 转换为 **DEX 格式**，以便 Android 设备运行。

- **D8 的特点：**
    1. **更小的 DEX 文件**：D8 生成的 `.dex` 文件比旧版 **DX 编译器** 生成的更小，提高了应用的性能。
    2. **更快的编译速度**：D8 在运行时性能优化上比 DX 更快，占用更少的资源。
    3. **更好的调试支持**：支持 Java 源代码级别的调试，并保留更好的调试信息。
    4. **默认支持 R8**：D8 可以与 **R8（代码压缩 & 混淆工具）** 结合使用，进一步优化应用体积和性能。

- **D8 vs DX：**
    - **D8** 是 DX 编译器的替代品，并在 Android Gradle 插件 3.1+ 版本中成为默认编译器。
    - **DX（Dalvik eXchange）** 是较旧的 DEX 编译器，效率较低，已被 D8 取代。
