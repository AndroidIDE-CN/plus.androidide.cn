# Zipalign

**`Zipalign`** 是一个用于优化 Android 应用的工具，通常用于对已经构建好的 **APK** 文件进行优化，以减少 APK 文件的大小并提升性能。它主要通过确保文件对齐，使得 APK 中的资源文件和字节流能够在内存中更高效地加载，从而提升应用运行时的性能。

`Zipalign` 工具是 **Android SDK Build Tools** 的一部分

## **`Zipalign` 的主要功能：**
1. **优化 APK 文件：**
    - `Zipalign` 通过重新排列 APK 中的文件，使其对齐到 4 字节边界，这有助于在设备上更高效地加载和解压。
2. **减少 APK 大小：**
    - 优化后的 APK 文件会有更好的压缩比，这可以减少应用的最终文件大小，特别是在安装过程中，优化后的 APK 被加载到内存时表现更好。
3. **提升应用性能：**
    - 当 APK 中的文件（如图像、资源文件等）被对齐时，内存访问会更加高效，从而提升应用在设备上的性能。
