# 从Maven仓库下载依赖

:::tip 提示

目前我们支持了pom和bom依赖

:::

## **POM（Project Object Model）**
**POM** 是 Maven 项目的核心配置文件，通常命名为 `pom.xml`。它定义了项目的基本信息、构建配置、插件、依赖等内容。


## **BOM（Bill of Materials）**
**BOM** 是一种特殊类型的 POM 文件，它用于定义一组共同的版本号，以便简化项目依赖版本管理。BOM 并不是一个常规的项目文件，而是专门用来管理 **依赖版本** 的。



## **POM 和 BOM 的区别**
| **特性**           | **POM**                              | **BOM**                              |
|-------------------|--------------------------------------|--------------------------------------|
| **定义**           | 项目的核心配置文件，包含依赖、插件、构建等 | 用于集中管理和版本控制的 POM 文件        |
| **功能**           | 定义项目的依赖、构建和信息              | 只定义依赖的版本信息，用于管理版本控制 |
| **依赖管理**       | 包含具体的依赖版本                      | 仅在 `dependencyManagement` 中定义版本号，避免重复指定版本 |
| **是否独立使用**   | 是                                    | 否，必须作为父 POM 或者引用其他 POM 中的 `dependencyManagement` |
| **常见用途**       | 用于项目本身的配置和管理                | 作为版本控制工具，在多个项目中共享依赖版本 |
