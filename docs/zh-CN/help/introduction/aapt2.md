# Android Asset Packaging Tool 2

:::tip 提示

目前默认启用 **AAPT2** 因为谷歌已经弃用了 **AAPT**

:::

**AAPT2**（Android Asset Packaging Tool 2）是 **Android** 的一个工具，用于处理和打包应用中的资源文件（如布局、图像、字符串等）。它是 **AAPT**（Android Asset Packaging Tool）的升级版，旨在提高资源打包的效率和灵活性。AAPT2 是 **Android Gradle 插件** 的一部分，用于 **编译**、**打包** 和 **优化** Android 应用的资源。


## **AAPT2 的主要功能：**
1. **资源编译**
    - AAPT2 编译应用的 **资源文件**（如 XML 文件、图像、音频文件）并将它们打包为 APK 或 AAB 文件的一部分。

2. **增量编译**
    - AAPT2 引入了增量编译功能，只有修改过的资源才会重新编译，这大大加快了构建速度。

3. **资源优化**
    - AAPT2 通过移除未使用的资源，优化最终的 APK 或 AAB 大小。

4. **支持更复杂的资源结构**
    - AAPT2 更好地处理了复杂的 **资源类型**，例如 **多语言、分辨率的图片资源**，确保它们可以正确地被打包和管理。

5. **错误处理和诊断**
    - 与 AAPT 不同，AAPT2 提供了更好的 **错误消息** 和 **诊断信息**，使得开发者在处理资源错误时更加方便。



## **AAPT2 与 AAPT 的区别：**
| **功能** | **AAPT** | **AAPT2** |
|----------|----------|-----------|
| **性能** | 较慢，逐个资源处理 | 更快，支持增量编译 |
| **增量编译** | 不支持 | 支持增量编译，优化构建速度 |
| **资源错误处理** | 错误提示较少 | 错误信息详细，便于调试 |
| **并行处理** | 不支持 | 支持并行处理资源，提高效率 |
| **兼容性** | 旧版支持较多 | 支持现代 Android 构建方式 |
| **生成的资源文件** | 生成 `.apk` 文件 | 生成 `.ap_` 文件，支持 AAB 打包 |
