## 功能建议和提交

:::danger 提示

请详细阅读

:::

### Issue
- 保持提交信息简洁而详细。
- 使用以下提交类型之一作为前缀：
    - `feat:` 用于新增功能，可能是改进已有的功能。
    - `fix:` 用于修复，例如修复bug。
    - `style:` 用于与样式相关的特性和更新。
    - `refactor:` 用于重构代码库的特定部分。
    - `test:` 用于与测试相关的所有内容。
    - `docs:` 用于与文档相关的所有内容。
    - `chore:` 用于代码维护（你也可以使用表情符号来表示提交类型）。

示例：
- `feat: 使用新技术加快编译速度`
- `fix: 修复某些手机启动时崩溃的问题`
- `refactor: 重构 File.java 中的代码`
