# NDK 安装

:::warning **提示**

注意⚠️⚠️⚠️

**推荐进入QQ群下载NDK**

[jzinferno2-termux-ndk](https://github.com/jzinferno2/termux-ndk/releases/tag/v1) 这个可以直接安装

[lzhiyong-termux-ndk](https://github.com/lzhiyong/termux-ndk) 此版本不能直接安装需要修改

AIDE+版本 与 Ndk来源

其他AIDE也可以使用此安装器安装 ***ndk***

:::

## Plus安装步骤

1. 把此项目在AIDE+内**克隆**到本地
```
https://github.com/ZeroAicy/AIDE-Ndk-Install
```
2. 然后打开此项目
3. 修改`Main.java`的`main`方法的 `NdkZipFilePath`变量为 **Ndk具体路径**
4. 保存并运行即可

## 其他AIDE安装步骤
1. 把此项目在AIDE+内**克隆**到本地
```
https://github.com/ZeroAicy/AIDE-Ndk-Install
```
2. 然后使用AIDE+和你需要安装的AIDE打开此项目
3. 修改 ***Main.java*** 的`main`方法的 `NdkZipFilePath`变量为 **Ndk具体路径**
4. 首先 ***另外的AIDE保存并运行*** 但是先 ***不要点击运行*** ，然后 ***使用AIDE+进行编译*** ，切换回另一个AIDE再点击运行即可
