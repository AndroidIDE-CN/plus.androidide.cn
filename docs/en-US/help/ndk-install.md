# NDK Installation

:::warning Note

Attention ⚠️⚠️⚠️

[jzinferno2-termux-ndk](https://github.com/jzinferno2/termux-ndk/releases/tag/v1) can be installed directly.

[lzhiyong-termux-ndk](https://github.com/lzhiyong/termux-ndk) requires modifications and cannot be installed directly.

AIDE+ version and NDK source.

:::

## Installation Steps

1. **Clone** this project locally within AIDE+
```
https://github.com/ZeroAicy/AIDE-Ndk-Install
```
2. Open the project.
3. Modify the `ndkPath` variable in the `main` method of `Main.java` to the **specific NDK path**.
4. Save and run the project.
