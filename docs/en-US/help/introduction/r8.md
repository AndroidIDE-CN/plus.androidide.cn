# R8 Shrinker and Obfuscator

:::tip Note

R8 can only be enabled after configuring the Gradle file in an Android project.

:::

**R8 Shrinker and Obfuscator** is an official **Android** tool for **code optimization, shrinking, and obfuscation**. It is a replacement for **ProGuard** and is deeply integrated with **D8** to optimize Android app **DEX code**.

## **R8's Functions**
R8 primarily helps to **reduce APK size** and **improve runtime performance**. Its core features include:

1. **Code Shrinking**: Removes unused classes, methods, and fields, reducing the app size.
2. **Code Optimization**: Optimizes Java bytecode, such as inlining methods and removing dead code, to improve execution efficiency.
3. **Code Obfuscation**: Replaces class names, method names, and variable names to make the code harder to reverse-engineer.
4. **DEX Generation**: Works with **D8** to convert Java bytecode into optimized `.dex` files.

## **R8 vs ProGuard**

| **Feature**        | **R8**                              | **ProGuard**                           |
|--------------------|-------------------------------------|----------------------------------------|
| **Developer**      | Google                              | Guardsquare                           |
| **Functionality**  | Obfuscation + Shrinking + DEX conversion | Only obfuscation and shrinking        |
| **Speed**          | Faster (optimizes directly during D8 phase) | Slower (runs separately)              |
| **Default Enable** | Android Gradle Plugin 3.4+          | Must be manually configured           |
| **Compatibility**  | Supports ProGuard rules            | Only supports ProGuard                |

## **Using R8**
- **R8 is enabled after configuring the Gradle file in an Android project.**

- **Custom Obfuscation Rules** (compatible with ProGuard syntax):  
  In the `proguard-rules.pro` file, you can define rules, such as:

  ```proguard
  # Retain MainActivity and all its methods
  -keep class com.example.app.MainActivity { *; }

  # Retain classes and methods annotated with @Keep
  -keep @androidx.annotation.Keep class * { *; }

  # Disable code optimization (only obfuscation)
  -dontoptimize
  ```
