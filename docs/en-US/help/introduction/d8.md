# D8 Dex Compiler

:::tip Note

**D8** is enabled by default as Google has deprecated **DX**.

:::

**D8 Dex Compiler** is an official tool from **Android** used to convert **Java bytecode (.class files)** into **Dalvik executable files (.dex files)**.

## **Introduction to D8 Dex Compiler**

- **What is D8?**  
  D8 is the default **DEX compiler** used by **Android Studio** and the **Android Gradle Plugin**. Its purpose is to convert **Java bytecode** into **DEX format**, which is required for Android devices to run the code.

- **Key Features of D8:**
  1. **Smaller DEX Files**: D8 generates `.dex` files that are smaller than those produced by the older **DX compiler**, improving application performance.
  2. **Faster Compilation Speed**: D8 performs faster than DX in terms of runtime optimizations, consuming fewer resources.
  3. **Better Debugging Support**: D8 supports Java source-level debugging and retains better debugging information.
  4. **Default Support for R8**: D8 can work in conjunction with **R8 (code shrinking & obfuscation tool)**, further optimizing application size and performance.

- **D8 vs DX:**
  - **D8** replaces the DX compiler and became the default compiler starting from Android Gradle Plugin version 3.1+.
  - **DX (Dalvik eXchange)** is the older DEX compiler, less efficient, and has been replaced by D8.
