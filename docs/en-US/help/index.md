## Feature Suggestions and Submissions

:::danger Note

Please read carefully.

:::

### Issue
- Keep submission messages concise yet detailed.
- Use one of the following commit types as a prefix:
  - `feat:` for new features or improvements to existing features.
  - `fix:` for fixes, such as bug fixes.
  - `style:` for style-related features and updates.
  - `refactor:` for refactoring specific parts of the codebase.
  - `test:` for anything related to testing.
  - `docs:` for anything related to documentation.
  - `chore:` for code maintenance (you can also use emojis to represent commit types).

Examples:
- `feat: Use new technology to speed up compilation.`
- `fix: Resolve crash issue on certain devices during startup.`
- `refactor: Refactor code in File.java.`

### Pull Request
- Fork the repository.
- Write your code.
- Submit your code.
- Send a Pull Request.

::: note Additional Notes

- Please ensure you are using the latest version of ***AIDE Plus***, as the feature you are looking for may already be implemented in the latest release.
- Before asking questions, please ensure you have read [**The Art of Asking Questions**](/help/smart-questions.md).
- Please ensure you can respond to the author's replies promptly. Issues with no response for an extended period will be closed and archived.
- Issues will be handled on GitHub. If you do not have a GitHub account, please register first.

:::
